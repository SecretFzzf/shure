# Additional numerical checks for the revision

This directory supports the additional results in Sections 3.6, 4.3, 4.4 and
Appendices G and H. The original 8,640 main experiment records support the
unchanged primary analysis. The revised Figure 2 supersedes the Figure 2
generated by the original figure script.

From the parent directory of the extracted `analysis_support_upload/` folder,
with the current `ESM_1.zip` in that same directory, run:

```sh
python -m pip install numpy==2.3.5 pandas==3.0.1 scipy==1.15.3 matplotlib==3.11.2
python analysis_support_upload/07_revision_analysis/recompute_revision.py --esm ESM_1.zip --mask62-input analysis_support_upload/07_revision_analysis/mask62_input.csv --out reproduced_revision
```

The script reads the archived run- and configuration-level figures directly.
It writes the revision statistics and the new Figure 2 to the chosen output
directory. Data, imputation caches and model checkpoints are unnecessary for
these numerical checks. The original scripts still reproduce the original
transmission and selection statistics from archived records. The architecture
table recalculates Spearman correlations and uses the original archived
grouped-fold predictions' R-squared summaries.

## Inputs and outputs

- `mask62_input.csv` contains the 720 ETTh1 alternative-mask records with
  seeds and validation-relevant configuration metadata. Personal paths and
  bulky training curves are omitted. The deterministic comparison uses
  Mean, KNN and Spline at forecast seed 42 and checks matching recorded
  protocol, training configuration, model, imputation setting and window
  counts. BRITS and SAITS use different fitting budgets and are excluded from
  this comparison.
- `thresholds.csv` and `strata.csv` document valid and excluded counts,
  inversion rates and median ratios. The sign-only row uses all comparisons,
  including identical reconstruction errors.
- `group_intervals.csv` compares the original horizon groups and the
  dataset-stratified mechanism-by-rate groups.
- `adjusted_logistic.csv` reports descriptive odds ratios and finite-sample
  group-robust intervals from the valid contrasts. The block variable is
  dataset × mechanism × rate. The term `MAR_Block` denotes Block-MCAR.
- `signal_by_model.csv` and `matched_signal.csv` report the architecture-specific
  diagnostics and within-task differences among contrasts with lower IE.
- `mask62.json` reports the ETTh1 comparison for each mask's own valid
  set and the intersection of the two valid sets.
